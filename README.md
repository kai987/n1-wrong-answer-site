# JLPT N1 错题复习网站

初始数据：2025年12月 JLPT N1 非听力错题 35 题。

## 使用
1. 双击 `index.html` 即可在浏览器打开。
2. “今日复习”可以查看题目、你的旧错误选项、正确选项和解析。
3. “全部错题”可以搜索、筛选、编辑和删除。
4. “添加 / 编辑”可以持续把未来的新错题加入。
5. 复习进度保存在浏览器 `localStorage` 中。
6. 建议定期点击“导出 JSON”备份；换浏览器/电脑时再“导入 JSON”。
